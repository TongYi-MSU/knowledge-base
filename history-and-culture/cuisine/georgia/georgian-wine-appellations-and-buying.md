# 格鲁吉亚葡萄酒：经典 PDO 酒名、酒标与两瓶购买组合

## 一句话总结

**买干红先认 Mukuzani，半甜红先认 Kindzmarauli 或 Khvanchkara；想带走特别的格鲁吉亚传统工艺，可考虑一瓶干型 Qvevri 琥珀酒。** 这些名称是受保护的地理名称或风格提示，不是“顶级酒庄”保证；需继续看酒庄、具体年份和储存条件。

## 核心知识

### 1. PDO 到底是什么？

**PDO（Protected Designation of Origin，受保护原产地名称）**对葡萄来源、允许品种、部分生产要求等有规范。消费者看到的 **Mukuzani、Kindzmarauli、Khvanchkara** 等名称，主要是**产地酒名**，不是葡萄品种、也不是生产商名字。

> 2025-04-08 格鲁吉亚国家葡萄酒局公布，登记的葡萄酒 PDO 增至 **32 个**。此为当日史料，不作为 2026-10-27 实时数字。

### 2. 最值得认出的六种酒

| 酒名 | 色泽与甜度 | 主要葡萄 | 产区 | 风格理解 |
|---|---|---|---|---|
| **Mukuzani** | **干红** | **Saperavi** | Kakheti（卡赫季） | 深色、较有酒体和单宁，经典干红代表 |
| **Kindzmarauli** | **天然半甜红** | **Saperavi** | Kakheti（卡赫季） | 黑莓/樱桃类果香，甜酸平衡 |
| **Khvanchkara** | **天然半甜红** | **Aleksandrouli + Mujuretuli** | Racha（拉恰） | 红色水果风格、较柔和，产地差异明显 |
| **Akhasheni** | **天然半甜红** | **Saperavi** | Kakheti（卡赫季） | 另一种经典 Saperavi 半甜产地酒 |
| **Tsinandali** | **干白** | **Rkatsiteli + Kakhuri Mtsvane**（按产区规范） | Kakheti（卡赫季） | 清爽或有一定复杂度的经典白酒 |
| **Tvishi** | **典型天然半甜白** | **Tsolikouri** | Lechkhumi（列其胡米） | 水果香与甜酸平衡；具体产品以标签为准 |

**重要对比**：Mukuzani 与 Kindzmarauli **葡萄相同（Saperavi）**，酒的甜度与 PDO 不同；Kindzmarauli 与 Khvanchkara **甜度类别相同，但产区、葡萄不同**。因此“稳妥”与“更有地域代表性”是在比较选购目的，**不等于一款绝对比另一款高档**。

### 3. 选择两瓶酒：根据目的，不按等级

| 目标 | 第一瓶 | 第二瓶 | 选择逻辑 |
|---|---|---|---|
| **稳妥、家人较易接受** | Mukuzani 干红 | Kindzmarauli 半甜红 | 用同一品种理解干型 vs 半甜 |
| **展示格鲁吉亚地域与葡萄多样性** | Mukuzani 干红 | Khvanchkara 半甜红 | Kakheti + Racha；Saperavi + 两种其他红葡萄 |
| **希望红白各一瓶** | Mukuzani 干红 | Tvishi 半甜白 | 颜色、甜度、品种差异明显 |
| **突出独特酿造文化** | Khvanchkara 半甜红 | Qvevri Rkatsiteli / Kisi 干型琥珀酒 | 地方半甜红 + 古老带皮发酵风格，后者可能不符合所有人口味 |

> **这次讨论中的具体推荐记录（不是经现场核实的实时库存）**：曾以 *Chelti Mukuzani 2020* 和 *Chelti Kindzmarauli 2024* 举例。属于“稳妥对比组合”，不应仅凭酒名和年份推断酒庄品质，也不可将历史对话里的价格当成实时标价。

### 4. 酒标识别（格鲁吉亚语）

| 格鲁吉亚文 | 中文 |

| ღვინო | 葡萄酒 |
| წითელი | 红色 / 红葡萄酒 |
| თეთრი | 白色 / 白葡萄酒 |
| მშრალი | 干型 |
| ნახევრად მშრალი | 半干型 |
| ნახევრად ტკბილი | 半甜型 |
| ტკბილი | 甜型 |
| ქვევრი | Qvevri 陶罐 |

阅读次序：**甜度 → 品种 → PDO/产区 → 生产商 → 年份/批次 → 工艺和保存状态**。如标签只写 Saperavi，它并不自动等于 Mukuzani，也不自动代表干型。

### 5. 购酒前的质量判断

- **酒名≠酒庄**：PDO 是产区受保护名称，Chelti、Marani 等是生产商/商业品牌层面的信息。
- **看储存**：瓶体避高温与强光，留意漏液、瓶塞异常、明显氧化痕迹。
- **看年份**：大多数日常半甜酒以年轻饮用为主；部分结构良好的 Saperavi 干红具有陈年能力，不能一概而论。
- **价格不是质量的单调函数**：品种稀缺、产量、包装、旅游渠道、酒庄声誉都会影响价格；不要把“贵”直接解释为“最好喝”。
- **琥珀酒先小杯试饮**：可能有茶感、涩感，不一定像常见白葡萄酒那样清爽。
- **携带出境/入境**：各国海关与航司规则可能变化；此文不记录未经实时核验的中国免税限量，应以出行当日官方要求为准。

### 6. 如果只能记住三个选项

- 干红：**Mukuzani**
- 半甜红：**Kindzmarauli**（稳妥）或 **Khvanchkara**（多一种产区和葡萄）
- 文化体验：**Qvevri 干型琥珀酒**（如 Rkatsiteli 或 Kisi）
